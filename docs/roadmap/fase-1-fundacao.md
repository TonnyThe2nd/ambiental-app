# Fase 1 - Fundação da Base

## Objetivo

Estruturar o projeto e preparar a base técnica para desenvolvimento do app mobile e do backend.

## Entregáveis

- projeto Flutter inicial
- organização de pastas
- arquitetura base de módulos
- configuração de dependências
- ambiente de desenvolvimento documentado

## Tarefas

1. Inicializar Flutter app em `apps/mobile`
2. Configurar `pubspec.yaml` com dependências principais
3. Criar estrutura de pastas por feature e camada
4. Preparar camada de configuração `core/`
5. Definir padrão de estado (BLoC/Provider/Riverpod)
6. Criar testes básicos de infraestrutura

## Dependências

- Flutter SDK
- Dart SDK
- Firebase CLI
- Google Maps API key
- Firebase project configurado

## Critérios de aceite

- app inicia sem erro
- estrutura organizada e rastreável
- dependências principais instaladas
- documentação inicial pronta
